# Exercices Data Science

Recueil d'exercices et de travaux pratiques réalisés en Data Science : classification, régression, détection de fraude, nettoyage de données, et un petit tableau de bord Streamlit.

## Contenu

- `fraude.ipynb` — détection de fraude (classification, matrice de confusion, courbe ROC)
- `regression_l.ipynb` — régression linéaire (prix de maisons)
- `Fish.ipynb` — classification sur le dataset Fish (espèces de poissons)
- `Walmart_cleaned.csv` / `Walmart.csv` — nettoyage et préparation de données de ventes
- `Activité1.ipynb` à `Activité5.ipynb` — exercices de cours (manipulation de données, visualisation, modèles de base)
- `streamlit.py` / `script.py` — scripts annexes, dont une petite app Streamlit
- `confusion_matrix.png`, `roc_curve.png` — visualisations produites par les notebooks

## Prérequis

`pip install pandas numpy scikit-learn matplotlib streamlit jupyter`

## Statut

Travaux pédagogiques — chaque notebook est autonome et correspond à un exercice ou une activité de cours distincte.
